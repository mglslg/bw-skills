## 各脚本职责一览

| 脚本 | 行数 | 输入 | 输出 | 职责 |
|---|---|---|---|---|
| `extract.js` | 131 | 招标文件全文.md | extracted_config.json | 正则提取元数据/技术参数/商务条款 |
| `generate_md.js` | 210 | config.json | 投标文件骨架.md | 生成可编辑的 MD 骨架 |
| `generate_skeleton.js` | 240 | config.json | 投标文件骨架.docx | 生成 Word 骨架 + XML 后处理 |
| `fill_templates.js` | 170 | 模板 + 映射 | 填充后 docx | 往原始模板精准填空 |

## 关键设计决策

| 决策 | 原因 |
|---|---|
| 标题用 HeadingLevel | TOC 域代码依赖大纲级别 |
| XML 后处理改颜色 | docx 库无法覆盖 Word 默认蓝色主题 |
| XML 后处理加 outlineLvl | docx 库不生成 `<w:outlineLvl>`，TOC 的 `\o` 选项找不到目标 |
| resp 字段一律 `null` | 不编造内容，生成时自动填 `【待填写】` |
| 目录来自模板 | 不同发标单位章节名可能不同，以模板为准 |
| 产出放 `_output/` | 原始数据只读不写 |
